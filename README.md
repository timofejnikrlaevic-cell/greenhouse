# 🌱 Умная теплица — Индивидуальный проект (версия 2)

Учебный симулятор угроз информационной безопасности для IoT-систем автоматизации:
модель теплицы на MQTT, скрипт атаки с подменой команд и модуль защиты на HMAC,
с 3D-визуализацией в браузере и единым запуском одной командой.

## Состав системы

| Модуль | Файл | Роль |
|---|---|---|
| Теплица | `src/greenhouse.py` | публикует телеметрию, исполняет команды, проверяет HMAC в режиме защиты |
| Хакер | `src/hacker.py` | сниффер трафика и инъекция поддельных команд без подписи |
| Защита | `src/security.py` | подпись/проверка команд: HMAC-SHA256 + timestamp + анти-replay (nonce) |
| Мост | `src/ws_bridge.py` | MQTT ⇄ WebSocket и раздача веб-интерфейса |
| Визуализация | `web/` | 3D-сцена теплицы (Three.js), панель управления, журнал событий |
| Запуск | `run_all.py` | проверяет брокера, запускает все модули, открывает браузер |

## Установка

Требуется Python 3.10+ и Eclipse Mosquitto.

```bash
pip install -r requirements.txt
python generate_secret.py   # создаст .env со случайным секретом
```

Установка Mosquitto:
- macOS: `brew install mosquitto`
- Linux (Debian/Ubuntu): `sudo apt install mosquitto`
- Windows: установщик с mosquitto.org, затем в консоли `mosquitto -c mosquitto.conf`

## Запуск

```bash
# 1) брокер (если не запущен как служба)
mosquitto -c mosquitto.conf

# 2) всё остальное — одной командой
python run_all.py
```

`run_all.py` проверит брокера, запустит теплицу, хакера и мост, откроет `http://localhost:8000`.

## Сценарий демонстрации

1. **Норма** — телеметрия идёт, кнопки «Полив»/«Обогрев» управляют теплицей (команды подписаны HMAC).
2. **Атака** — нажмите «▶ Запустить атаку»: хакер сниффит телеметрию и шлёт поддельные команды
   без подписи. Обогрев взлетает до 100%, температура растёт до аварии, сцена краснеет.
3. **Защита** — нажмите «🛡 Включить защиту»: команды хакера отклоняются
   («⛔ Отклонено: bad signature»). Верните контроль: кнопкой «🔥 Обогрев» сбросьте до 0% —
   легальная подписанная команда принимается, температура падает.

## Топики MQTT

| Топик | Направление | Содержимое |
|---|---|---|
| `greenhouse/telemetry` | теплица → всем | температура, влажность, состояние актуаторов |
| `greenhouse/commands` | панель/хакер → теплица | команда `{action, value, ts, nonce, hmac?}` |
| `greenhouse/security` | теплица → всем | события «принято»/«отклонено» |
| `system/attack_control` | мост → хакер | вкл/выкл атаки |
| `system/mode` | мост → теплица | normal / defended |

## Роли в команде

- **Студент 1 (автоматизация):** `greenhouse.py`, `ws_bridge.py`, `web/` — телеметрия, мост, 3D-сцена.
- **Студент 2 (ИБ):** `hacker.py`, `security.py` — анализ уязвимостей MQTT, атака, HMAC-защита.
